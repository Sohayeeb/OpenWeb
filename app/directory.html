Elsewhere

Other sites have keys, not names.

An OpenWeb address is a public key written as ow1…. There is no registrar and no lookup table, so a link has to carry the key with it. The gateway's sites page lists everything this machine has crawled.

Add a site to your index

node packages/cli/dist/index.js crawl <address> \
  --dir .openweb --max 200

Crawling is a choice, not a background process. Coverage is exactly what you asked for.

The gate

A directory is a promise to have looked.

OpenWeb cannot delete the rest of the internet. It can refuse to carry it. The browser extension in this repository exists for that one job: allow the local gateway and the sites you have reviewed, block the rest. No allow-once button. Adding a site is a deliberate edit.
