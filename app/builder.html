Builder

One page. One file. No framework.

The builder turns a few fields into one self-contained HTML file. It has no scripts, no external fonts, and nothing fetched from another server. Save it in a folder, publish the folder, and the page is online while your computer is.

From the app

Fill in the form, publish the page.

The gateway runs the builder on the server, so a published page never needs JavaScript to exist. In the desktop app the preview has a publish this page button; a plain gateway offers the same file as a download.

Or go straight to /builder on this gateway.

From the terminal

The same output, one command.

openweb new my-site --title "My page" --tagline "A small thing I made"
openweb serve my-site

The folder contains exactly one file, index.html. Edit it by hand afterwards if you like; it is ordinary HTML and CSS.

Rules the builder keeps

Staticno scripts in the output
Self-containedstyles inline, no CDN
Escapedtext cannot inject markup
Yoursa file, not an account
