Search

A search engine small enough to own.

There is no global index and no company behind this box. The gateway on your machine answers from a JSON file built by a crawler you started. Coverage is the honest part: it is exactly what you seeded.

This form is handled by the local gateway at /search. It does not send your query anywhere else.

Query syntax

Small, but not a toy.

WriteGet
tomato soilBoth words must appear.
"slow garden"Those words, in that order.
tomato -coffeePages with tomato, without coffee.
title:gardenThe word must be in the title.
compost OR beansEither word may appear.

Words are Porter-stemmed, so tomatoes matches tomato. Ranking is BM25 with a title boost. No personalization, no click tracking, no ads.

Build the index

You decide what gets read.

Crawling is manual. Point the crawler at an address and it follows the links it finds, up to a depth and a page limit. 

node packages/cli/dist/index.js crawl <address> \
  --dir .openweb --max 200

node packages/cli/dist/index.js search "slow garden" \
  --dir .openweb

The index is .openweb/index.json. Copy it, inspect it, or delete it. It is yours.

Machine-readable

The same answer, as JSON.

/search?q=coffee&format=json

{
  "query": "coffee",
  "cached": false,
  "tookMs": 0.184,
  "total": 1,
  "indexed": 9,
  "results": [ … ]
}

The gateway caches the parsed index by mtime and keeps the last 256 queries. Repeat searches are effectively free.
